# Поиск оператора ЭДО

Веб-приложение для поиска оператора электронного документооборота (ЭДО) по коду идентификатора.

## Описание

Приложение позволяет определить оператора ЭДО по первым трём символам идентификатора (например, `2BM...`, `2AE...` и т.д.).

## Функционал

- **Поиск по коду**: Введите код оператора (начиная с `2B...` или полный идентификатор)
- **Автоопределение**: Достаточно ввести первые 3 символа ID
- **База операторов**: Поддерживает основные российские операторы ЭДО:
  - Такском / 1С-ЭДО
  - Калуга-Астрал / 1С-ЭДО
  - Тензор / СБИС
  - СКБ Контур / Диадок
  - И другие

## Использование

1. Откройте `index.html` в браузере
2. Введите код оператора в поле ввода
3. Нажмите «Найти» или клавишу Enter
4. Получите название оператора
